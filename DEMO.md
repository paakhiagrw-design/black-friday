# RIP — three-minute demonstration

**The end of unnecessary returns.** One Raspberry Pi, returned in Dublin, can travel to a consenting local buyer. The two image comparisons are real OpenAI requests. Payment, courier movements and the inspection checklist in this walkthrough are demonstration actions.

## Before presenting

1. Use the [Railway store](https://black-friday-production.up.railway.app/store) with the server OpenAI key and seller code configured. For a rehearsal use a fresh isolated file with `export DATABASE_PATH="$(mktemp -d)/reroute.db"`, then `npm run db:init && npm run db:seed && npm run dev`. Use `http://localhost:3000` for the same paths. Preserve any existing demo database.
2. Save the [return photo of the Raspberry Pi](https://black-friday-production.up.railway.app/demo/pi-side.webp) and the [incorrect keyboard photo](https://black-friday-production.up.railway.app/catalogue/keyboard.webp) to your laptop. Both also ship in the repository under `public/`. The [top-view catalogue reference](https://black-friday-production.up.railway.app/demo/pi-top.webp) loads automatically.
3. Open separate store, verification, matches, delivery, inspection, tracking and dashboard tabs. Sign into the seller workspace as `seller` with the private code. Refresh a tab to fetch newly created records. Match the product name and the return, buyer-order and tracking references shown during **your** run.
4. To fit both scans into three minutes, prepare the mismatch before the clock starts. Choose **Niamh Kelly**, open **Your orders**, find **Raspberry Pi 4 Model B**, choose **Request a return**, enter **Duplicate gift**, select **like new**, attach the keyboard photo, and click **Submit return request**. In a separate verification tab, select Niamh’s return and click **Run Vision Scan**. Keep the resulting discrepancy visible for the presentation.

Demonstrate all five checks, enter SKU **RR-TEC-PI4** and inspection notes, then choose **Pass inspection → Issue simulated refund**. Show the €65.00 refund and €3.00 reward. |
| 2:45–3:00 | **Outcome.** At [/tracking](https://black-friday-production.up.railway.app/tracking), select the same reference and choose **Simulate dispatch → Simulate delivery**. In the isolated Aoife-to-Cian rehearsal, the completed route added €12.51 saved, an estimated 124.21 km and 26.08 kg CO₂e. The dashboard displays miles, and totals include all completed reroutes. |

A return consumes its delivered purchase. Use another isolated database for a repeat performance. If the provider or evidence is unavailable, the panel displays the error and the presenter can continue with manual review. Describe only findings actually returned by OpenAI.
